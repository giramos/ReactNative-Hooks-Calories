Para crear un proyecto React-Native:
    npx @react-native-community/cli init CaloriesApp
    Otra forma (más genérica)
        npx create-expo-app CaloriesApp
        npx create-expo-app CaloriesApp --template blank-typescript
        npx create-expo-app CaloriesApp --template blank



Lanzar la app    
    npm run start

Instalar manualmente
    Expo 
        Instalación en tu proyecto:
            npm install -g expo-cli exp
        NOTA: para crear un proyecto con expo integrated

    Navigation
        NOTA: para crear un proyecto con navegation instalado y plantilla
            npx create-expo-app@latest --template react-navigation/template
        Instalación en tu proyecto:
            npm install @react-navigation/native
        Referencia:
            https://reactnavigation.org/docs/getting-started
    ReactNative elements
        Referencia: https://reactnativeelements.com/
        NOTA: para crear un proyecto con elements instalado y plantilla
            npx create-expo-app --template @rneui/template
        Instalación en tu proyecto:
            npm install @rneui/themed @rneui/base
            npm install @rneui/base@edge @rneui/themed@edge
